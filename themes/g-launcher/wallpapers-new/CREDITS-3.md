# Replacement wallpapers, batch 3: sources and licences

All files are 1080 x 2340 WebP, centre-cropped to portrait from the originals. Cropping
and re-encoding are the only changes. Sourced 15 November 2026.

Check each licence yourself before publishing a paid pack. The attribution lines
below belong in the app's Licences screen.
